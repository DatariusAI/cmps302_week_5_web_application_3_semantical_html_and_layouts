An Alpine countries website built with semantic HTML5 elements and CSS layout techniques. Continues the Alps tourism theme with a focus on proper document structure and page layouts.

## Topics Practiced

- Semantic HTML5 elements for meaningful document structure
- CSS layout techniques (floats, positioning, margins)
- Multi-page site with `index.html` and `tourism.html`
- Image integration with Alpine country photographs
- Stylesheet organization in a dedicated `css/` folder

## Project Structure

```
index.html          # Home page - Alps geography and ecology
tourism.html        # Tourism destinations and resorts
css/                # Stylesheet(s)
Alps.jpg, Austria.jpg, France.jpg, ...  # Alpine country images
```

## How to Run

Open `index.html` in any web browser.
